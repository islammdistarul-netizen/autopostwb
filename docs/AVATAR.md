# Аватар: как устроен и как делать арт

Аватар — не видео и не нейросетевая анимация. Это **набор статичных PNG**, которые Remotion переключает покадрово. Каждый кадр — чистая функция от номера кадра: поза и эмоция берутся из таймлайна манифеста, форма рта — из `mouth-cues.json` (Rhubarb), моргание — из детерминированного расписания. Никакой генерации во время рендера.

## Два режима сборки (`character.json` → `mode`)

| | `layered` | `composite` (рекомендуется для сгенерированного персонажа) |
|---|---|---|
| Слои | тело **без лица** + накладка лица + накладка рта | полный кадр поза×эмоция (лицо нарисовано) + накладка рта |
| Файлов на старт | 5 тел + 4 лица + 8 ртов + 1 моргание = 18 | 5 тел (нейтральное лицо) + 8 ртов (+ по желанию кадры эмоций) |
| Требование к арту | голова в **одной точке и одном размере** во всех телах | лицо согласовано в каждом кадре само по себе; голова всё равно должна быть примерно в одном месте (для рта) |
| Когда выбирать | рисованный вручную персонаж в векторе | персонаж из Midjourney / Nano Banana / FLUX по референсу |

В `composite` эмоция без своего кадра автоматически откатывается на нейтральный кадр позы — можно начинать с 5 картинок и докладывать эмоции постепенно.

## Что должно быть в `assets/characters/<id>/`

```
character.json      индекс спрайтов, координаты, режим, блок generation
reference.png       референс персонажа для генерации (лицо крупно + по пояс, нейтрально)
bodies/             body_<pose>.png — 720×960, прозрачный фон, персонаж по пояс, стоит на нижнем крае
frames/             <pose>_<mood>.png  (только composite)
faces/              face_<mood>.png, eyes_closed.png   (layered; накладки ~380×260)
mouths/             mouth_A..F.png, mouth_X.png, mouth_closed.png (накладки ~200×120)
```

Размер тел задаётся `spriteCanvas` (по умолчанию 720×960) — интейк подгоняет любой вход под него. Координаты накладок (`layers.faces.offset`, `layers.mouths.offset`, `layers.blink.offset`) — смещение от **центра** спрайта тела в пикселях; проверяются по превью с перекрестиями.

## Спецификация для генерации / художника

- **Референс** один: персонаж по пояс, три четверти в камеру, нейтральное лицо, **рот закрыт**, простой фон. Все дальнейшие кадры генерируются «как на референсе» (`generation.stylePrompt` + `posePrompts` + `moodPrompts` в `character.json`).
- Стиль фиксируется текстом в `stylePrompt`: плоский вектор / cel-shading / толщина линий / палитра / без градиентов. Меняется один раз, применяется ко всем.
- Позы (базовые 5): стоит расслабленно; указывает пальцем в камеру; рука у подбородка; руки вскинуты у головы; руки в боки. Эмоции: нейтрально; улыбка; скепсис (одна бровь); удивление.
- Во всех кадрах **рот закрыт** — поверх ложится слой ртов. Ротовой слой (8 форм) рисуется один раз под этого персонажа: Rhubarb-виземы A (закрыт, губы сжаты), B (приоткрыт, зубы), C (открыт «э»), D (широко «а»), E (округлён «о»), F (вытянут «у»), X (покой).
- Фон при генерации — сплошной белый или зелёный: `rembg` (модель `isnet-anime`) снимает его автоматически. OpenAI `gpt-image-1` умеет сразу отдавать прозрачный PNG.

## Конвейер добавления спрайта

```bash
# 1. сгенерировать недостающую позу по референсу (никогда не во время рендера)
npm run sprites:generate -- default --pose holding_laptop            # CF_SPRITE_BACKEND=openai|gemini
# или взять рисунок художника
npm run sprites:prepare  -- default ~/art/laptop.png --pose holding_laptop

# 2. посмотреть storage/cache/sprite-candidates/default/holding_laptop.preview.png
#    красное перекрестие = рот, синее = лицо. Если не совпадает — править offset в character.json

# 3. утвердить: файл копируется в assets/characters/default/bodies/, поза регистрируется в character.json
npm run sprites:prepare  -- default --approve --pose holding_laptop

# эмоция для позы (composite):
npm run sprites:generate -- default --pose holding_laptop --mood happy --approve
```

Сценарист, встретив позу, которой у персонажа нет, подставляет ближайшую известную и пишет запрос в `storage/cache/sprite-requests.json`. `npm run doctor` показывает очередь; `npm run sprites:generate -- default --from-requests` обрабатывает её целиком.

## Движение без новых картинок

- пружинный «поп» при смене позы, дыхание (синус), лёгкий наклон — уже есть;
- моргание: `layers.blink` + `motion.blinkEverySeconds` / `blinkFrames`, два наложенных цикла разной длины — выглядит нерегулярно, остаётся детерминированным;
- смена рта каждые 80–120 мс по Rhubarb.

Следующие шаги при желании: 2–3 кадра «говорящих рук» на позу (цикл), лёгкий zoom камеры на `shocked`/`surprised`.
