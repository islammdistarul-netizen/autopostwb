Документ отвечает на три вопроса: **какие инструменты и почему** (с альтернативами и минусами), **что было не так в исходной спеке и что исправлено**, **в каком порядке запускать** (локально или сразу на сервере). В конце — первый шаг с точными командами.

## 1. Что уже сделано

Кодовая база собрана целиком по `CLAUDE.md`, а не «скелетом»: типы с zod-валидацией, все 6 модулей, оркестратор с lock-файлом и архивом ранов, CLI, `doctor`, серверный setup-скрипт, systemd-таймер, compose для Postiz.

Проверено в изолированной среде (без сети к YouTube/Microsoft, поэтому TTS/yt-dlp/rhubarb проверялись на уровне контрактов, а не живых вызовов):

| Сборка webpack-бандла Remotion | ок |

## 2. Аудит инструментов: выбор, альтернативы, вердикт

### 2.1 Парсинг конкурентов — `yt-dlp`
- **Плюсы:** бесплатно, отдаёт просмотры/лайки/комментарии/подписчиков одним `--dump-json`, умеет `ytsearchdate` (свежее, а не вечные хиты), даёт **автосубтитры YouTube с пословными таймингами** — это делает Whisper запасным вариантом, а не основным.
- **Минусы:** Instagram и TikTok через yt-dlp работают нестабильно (нужны куки, ломается при каждом изменении на их стороне). YouTube на датацентровых IP регулярно требует «подтвердите, что вы не бот».
- **Альтернативы:** Apify/Bright Data акторы для Instagram/TikTok (платно, $30–100/мес, стабильно); официальные API (YouTube Data API v3 — бесплатно 10k units/день, даёт статистику без скрапинга; TikTok Research API — только по заявке).
- **Вердикт:** MVP на YouTube Shorts через yt-dlp (в коде: `YTDLP_COOKIES`, `YTDLP_EXTRA_ARGS` для прокси). Instagram/TikTok-разведку добавлять вторым этапом через Apify, если ниша требует.

### 2.2 Транскрипция — `faster-whisper`
- **Плюсы:** офлайн, бесплатно, `medium` на CPU ≈ 1–2× реального времени, хорошее русское качество.
- **Минусы:** `large-v3` на CPU нереален (нужен GPU); `medium` съедает ~3 ГБ RAM.
- **Что сделано:** сначала берём автосубтитры YouTube (`json3`, пословно, мгновенно), Whisper — только если их нет (`intelligence.whisperFallback`). На практике 80–90 % роликов обходятся без Whisper.
- **Альтернативы:** ElevenLabs Scribe / Deepgram (платно, быстро, отличный русский).

### 2.3 Сценарий — `claude -p`
- **Плюсы:** уже есть на сервере, headless-режим, никаких SDK.
- **Минусы:** модель — творческая, ей нельзя доверять арифметику. Поэтому LLM пишет только **черновик** (озвучка по сегментам + слайды + подпись), а кадры, тайминги, ассеты и каналы вычисляет код. Черновик валидируется zod-схемой, 3 попытки.
- **Альтернатива:** Anthropic SDK напрямую (нужен `ANTHROPIC_API_KEY`), полезно, если завод переедет на сервер без Claude Code. Точка замены одна — `draftViaClaude()`.
- **Для смоука без LLM:** `CF_SCRIPT_PROVIDER=template`.

### 2.4 Озвучка — `edge-tts`
- **Плюсы:** бесплатно, Dmitry/Svetlana — лучшие бесплатные русские голоса, отдаёт **WordBoundary-события** → точные пословные тайминги без второго прохода Whisper по своему же аудио (в спеке этот момент не был закрыт).
- **Минусы:** неофициальный эндпоинт Microsoft — может отвалиться или начать лимитировать без предупреждения; формально не для коммерческого использования.
- **Альтернативы:** ElevenLabs (лучшее качество, платно, есть timestamps API; MCP-коннектор уже подключён к этому проекту), Yandex SpeechKit (нативная русская просодия, платно), Silero (офлайн, бесплатно, средне).
- **Вердикт:** edge-tts как основной, ElevenLabs — запасной путь; точка замены — `synthesizeVoice()`, контракт `VoiceResult` (wav + captions) уже под это рассчитан.

### 2.5 Липсинк — Rhubarb
- **Критично:** в спеке указан `-r sound`. **Такого значения у Rhubarb нет** — бинарник его отклонит. Языконезависимый распознаватель называется `-r phonetic`. Исправлено везде (код, `CLAUDE.md`, `doctor` проверяет наличие режима).
- Добавлен `--extendedShapes X`: Rhubarb выдаёт только A–F + X, ровно наш набор спрайтов (иначе пришлось бы схлопывать G/H на соседей — это тоже реализовано как страховка).
- **Альтернатива:** без липсинка вообще — рот по амплитуде звука (примитивно, выглядит хуже). Rhubarb оправдан.

### 2.6 Видео — Remotion
- **Плюсы:** React-композиция, детерминированный рендер, `calculateMetadata` считает длительность от `voice.wav`, `OffthreadVideo` не упирается в Chromium при декодировании.
- **Минусы и что учтено:**
  - Нужен `chrome-headless-shell` (старый headless-режим). Обычный Chrome «new headless» не подходит — проверено, Remotion падает. Remotion скачивает shell с `remotion.media`; если хост закрыт — `CF_BROWSER_EXECUTABLE`.
  - **Лицензия:** бесплатно для физлиц и компаний ≤ 3 человек; иначе — платная company license. Проверить перед коммерческим запуском.
  - Требует `zod@4` (несовпадение версий ломает хуки) — зафиксировано `4.5.4`.
  - RAM: 2 воркера 1080×1920 ≈ 2–3 ГБ.
- **Альтернатива:** чистый ffmpeg с `drawtext` — без спрайтовой анимации и караоке; не тянет задачу.

### 2.7 Карусель — Satori + Resvg
- **Плюсы:** без браузера, 6 слайдов за ~1 с, шрифты из буферов.
- **Минусы и что учтено:** Satori не умеет переменные шрифты (opentype.js) — нужны **статичные** TTF; эмодзи не рисуются (вырезаются в `stripUnrenderable`, LLM-промпт запрещает их); только Flexbox.
- Шрифты Inter 400/700 и Unbounded 500 добавлены в репозиторий (OFL) и проверены на кириллицу; setup-скрипт умеет их пересобрать через Google Fonts API.

### 2.8 Дистрибуция — Postiz
- **Плюсы:** один OAuth-хаб для IG/TikTok/YouTube/Telegram/VK, планировщик, публичный API.
- **Минусы и что учтено:**
  - Путь API в спеке (`/api/posts`) — внутренний. Публичный: `{host}/api/public/v1/{integrations|upload|posts}`, заголовок `Authorization: <key>` без Bearer. Исправлено в конфиге и клиенте.
  - **Лимит 30 запросов/час** на публичный API. Один цикл = ~10 запросов (7 слайдов + рилс + 2 поста). Клиент повторяет 429 с backoff; таймер ставит ≤ 2 цикла/час.
  - Instagram/TikTok **скачивают медиа с Postiz**, поэтому Postiz нужен публичный HTTPS-домен, даже если завод ходит в него по localhost.
  - Провайдерам нужны `settings` (YouTube — `title`/`type`, TikTok — `privacy_level` и т.д.) — добавлено `channelSettings` в `postiz.config.json`.
  - Instagram требует Facebook Business App с прохождением review; TikTok — audit приложения. Это самый долгий шаг во всём проекте (1–3 недели), его надо запускать **в первый день**, параллельно с остальным.
- **CLI `postiz posts:create`** оставлен как опциональный адаптер; основной путь — REST, потому что его формат задокументирован и валидируется.

## 3. Недочёты исходной спеки — найдены и исправлены

| # | Проблема | Исправление |
|---|---|---|
| 1 | `rhubarb -r sound` не существует | `-r phonetic` + `--extendedShapes X`, `doctor` проверяет |
| 2 | Postiz `http://localhost:5000/api/posts` — не публичный API | `/api/public/v1`, upload → posts, ключ без Bearer, retry 429 |
| 3 | Неясно, откуда брать пословные тайминги для караоке | `scripts/tts.py` собирает WordBoundary edge-tts → `captions.json` |
| 4 | Whisper на всех роликах конкурентов — дорого и медленно | автосубтитры YouTube `json3` первыми, Whisper — fallback |
| 5 | JS `\b` не работает с кириллицей (классификатор хуков молча возвращал `unknown`) | lookbehind `(?<![а-яёa-z0-9])`, покрыто юнит-тестом |
| 6 | Формула виральности: shares/saves недоступны из YouTube | формула сохранена, веса в конфиге; фактически работает на лайках/комментариях — это надо помнить при интерпретации |
| 7 | Таймлайн аватара по счёту слов ломается при другом токенайзере TTS | границы сегментов по доле символов — устойчиво к любому токенайзеру |
| 8 | Нет защиты от параллельных запусков (cron) | lock-файл с проверкой живого PID |
| 9 | Артефакты перезаписываются каждым раном — невозможно отследить плохой пост | архив `storage/artifacts/runs/<runId>/` + ретеншн (`retention.keepRuns`, `rawDays`) |
| 10 | Повтор тем | история тем на 90 дней + Jaccard-дедуп по стеммированным ключевым словам |
| 11 | Юридика ниши (ст. 25 ФЗ «О рекламе») | автоматический футер «БАД. Не является лекарственным средством.» при упоминании БАД/витаминов; запрет обещаний в промпте |
| 12 | Эмодзи в тексте слайдов исчезают в Satori | вырезаются + запрет в промпте |
| 13 | Переменные шрифты не работают в Satori | статичные TTF в репо + проверка `fvar`/кириллицы |
| 14 | Remotion требует старый headless Chrome, `remotion.media` может быть закрыт | `CF_BROWSER_EXECUTABLE`, проверка в `doctor` |
| 15 | Zod 3 несовместим с Remotion 4.0.5xx | закреплён `zod@4.5.4` |
| 16 | Координаты лица/рта в `character.json` были неверны (глаза над головой) | пересчитаны относительно центра спрайта, проверено стоп-кадром |
| 17 | Нет провайдерских `settings` для Postiz | `channelSettings` в конфиге, `title` для YouTube берётся из хука |

## 4. Риски будущего и предохранители

| Риск | Что произойдёт | Предохранитель в коде / что делать |
|---|---|---|
| YouTube блокирует IP сервера | `intel` вернёт 0 роликов | `YTDLP_COOKIES` из залогиненного браузера; резидентный прокси через `YTDLP_EXTRA_ARGS`; понятная ошибка вместо пустого прогона |
| edge-tts перестал отвечать | `produce` падает на шаге 3 | ошибка с диагностикой; замена на ElevenLabs в одной функции |
| Postiz 429 / упал | публикация не проходит | retry с backoff; `publish` можно перезапустить отдельно — артефакты лежат в `artifacts/runs/<runId>` |
| Instagram отклонил медиа (кодек/размер) | пост в Postiz с ошибкой | рендер уже даёт H.264 yuv420p 1080×1920 30 fps AAC — совместимый профиль; следить за длительностью ≤ 90 с |
| LLM выдал невалидный JSON | — | zod-схема, 3 попытки, затем стоп (лучше пропустить слот, чем опубликовать мусор) |
| Одна тема опубликована дважды | репутация | история тем + дедуп; `pickTopic` пропускает использованные |
| Диск забился медиа | всё падает | ретеншн ранов и raw-аудио; `storage/` в `.gitignore` |
| Cron запустился поверх живого рана | порча `staged/` | lock-файл |
| Заменили спрайты, но не имена | рендер падает | `doctor` сверяет `character.json` с файлами; имена не придумываются ни LLM, ни кодом |
| Обновление Remotion/Postiz сломало API | — | версии зафиксированы в `package.json`; compose и клиент содержат ссылки на первоисточник формата |
| Шаблон/промпт сгенерировал обещание «вылечит» | юридический риск | запрет в промпте + `bannedTopics` фильтруют источник; рекомендуется ревью первых 10 постов человеком (`--mode draft`) |

## 5. Локально или сразу на сервере?

**Сразу на сервере.** Аргументы:

1. Вся цепочка — Linux-нативная (rhubarb-бинарь, ffmpeg, chrome-headless-shell, Docker для Postiz). Локальная Windows/Mac-среда не повторит серверную, а «работает у меня» тут ничего не значит.
2. Postiz с Instagram/TikTok **обязан** быть на публичном HTTPS-домене — локально это не проверить в принципе.
3. Setup-скрипт идемпотентен, `doctor` показывает, чего не хватает; порог входа на сервере ниже, чем поддержка двух сред.
4. Итерации по дизайну композиции делаются в Remotion Studio через SSH-туннель (`npm run studio`, порт 3000) — локальная машина не нужна.

Что **имеет смысл** делать не на проде: первые 10–20 постов публиковать через `--mode draft` и утверждать руками в интерфейсе Postiz. Это «локальный режим» в правильном смысле — ручной контроль качества, а не другая машина.

**Требования к серверу:** Ubuntu 22.04/24.04, 4 vCPU, 8 ГБ RAM (Postiz-стек ~1.5 ГБ, Remotion ~3 ГБ, Whisper medium ~3 ГБ — но они не одновременно), 60 ГБ SSD, публичный домен для Postiz. Без GPU. Не датацентр, который YouTube уже забанил (Hetzner/OVH обычно ок с куками).

## 6. Пошаговый план

| Этап | Что | Критерий готовности |
|---|---|---|
| **0. Параллельно, день 1** | Завести Facebook Business App (Instagram), TikTok Developer App, YouTube OAuth client, Telegram-бота, VK-приложение. Подать на review IG/TikTok. | заявки поданы (ждать 1–3 недели, не блокирует остальное) |

| **3. Смоук без внешних сервисов** | `CF_SCRIPT_PROVIDER=template npm run produce -- --skip-render`, затем полный `produce` | есть `final_reel.mp4` и 6 слайдов, глазами проверены |
| **4. Разведка** | `npm run intel` на реальных ключевых словах ниши; подобрать `minViews`, `videosPerKeyword`, куки | `topics.json` содержит ≥ 10 кандидатов с транскриптами |

| **9. Обратная связь** | раз в неделю: статистика постов → веса скоринга/промпт (скилл `carousel-performance-loop`) | рост сохранений/охвата |

## 7. Первый шаг реализации (сегодня)

```bash
# на сервере, пользователь deploy с sudo
sudo mkdir -p /opt/autopostwb && sudo chown deploy:deploy /opt/autopostwb
git clone <repo-url> /opt/autopostwb && cd /opt/autopostwb
git checkout claude/eloquent-lamport-pxecqs

sudo bash scripts/setup-server.sh          # 5–10 минут
cp .env.example .env                       # пока без POSTIZ_API_KEY
npm run doctor                             # ожидаем FAIL только по b-roll/music/Postiz

npm run sprites:placeholder
PEXELS_API_KEY=... bash scripts/fetch-broll.sh "healthy food kitchen" 4
PEXELS_API_KEY=... bash scripts/fetch-broll.sh "gym training" 4
bash scripts/normalize-music.sh ~/tracks   # любые royalty-free треки

npm run doctor                             # всё зелёное, кроме Postiz
CF_SCRIPT_PROVIDER=template npm run produce
ls -la storage/artifacts/ storage/artifacts/carousel/
```

Если `final_reel.mp4` и слайды на месте — сервер готов, дальше этап 4 (`npm run intel`) и параллельно этап 0 (заявки в IG/TikTok).

Если Remotion не может скачать headless-shell (`403 remotion.media`): `sudo apt install -y chromium` не поможет (новый headless). Вариант — `npx playwright install chromium-headless-shell` и `CF_BROWSER_EXECUTABLE=~/.cache/ms-playwright/chromium_headless_shell-*/chrome-linux/headless_shell`.
