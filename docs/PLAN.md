| `okkamitsuki/obtube` | **Существует**, 05.2026: C-плагин OBS, 4 состояния (idle/talking × глаза открыты/закрыты) + случайное моргание. Подтверждает подход, код не переносим (OBS, не Remotion) | моргание у нас уже детерминированное |

Но это **Next.js + Tailwind + html-to-image** — экспорт через браузер, `bun dev` на порту — не headless и **не Satori/Resvg**, как утверждало исследование. Ценность: дизайн-система (12 типов слайдов: stats, checklist, comparison, quote, process; 5 шрифтов × 8 поверхностей × 11 акцентов) | переносим **идеи** типов слайдов в наши Satori-шаблоны, код не берём |
| `gyoridavid/short-video-maker` | **Существует**, но последний коммит 06.2025; Kokoro — только английский (сами пишут в Limitations) | референс архитектуры, не более |

**Что дал `ossclip` для нашего Postiz-клиента (проверено на живом инстансе, 08.2026):** каждому посту обязателен `settings.__type` = идентификатор платформы из `GET /integrations`; YouTube требует `settings.type` (приватность), Instagram — `settings.post_type` — без них Postiz отклоняет **весь** запрос уже после загрузки видео; лимит — **90 постов/час** (не «30 запросов», как я писал ранее); Instagram не принимает файлы ≈ >100 МБ; `tags: []` обязателен. Всё это теперь в `buildPostSettings()` и `checkPlatformCaps()`.
| Прямые Python-скрипты VK/Telegram «на всякий случай» | противоречит выбранному принципу «только через Postiz», удваивает поддержку OAuth | не делаем |
| `engine.sh` с `set -e`, ключами в теле скрипта, без lock и без ретраев | упадёт на первом сбое, cron запустит второй экземпляр поверх первого, секреты попадут в git | заменён оркестратором + lock + `.env` + systemd |

## 3. Голос: варианты и решение

| Провайдер | Русский | Цена | Пословные тайминги | Коммерческое использование | Роль |
|---|---|---|---|---|---|
| **Yandex SpeechKit** | отличный | ~1 ₽/ролик | нет → выравнивание Whisper | да | **основной для продакшена** |
| **edge-tts** | хороший | 0 | да | серая зона | по умолчанию для тестов / запасной |
| **Piper** | средний | 0, офлайн | нет → Whisper | да (MIT) | бесплатный и легальный запасной |
| **ElevenLabs** | лучший | $5–22/мес | да | да | премиум |
| Silero / XTTS / Fish | хороший | 0 | нет | **нет** (NC) | не используем |

Переключение — `voice.defaultPreset` в `config/app.config.json`; пресеты `male` (edge), `yandex_alena`, `yandex_filipp`, `piper_irina`, `eleven`. Для провайдеров без таймингов субтитры выравниваются по нашему же тексту (точность ±50 мс).

## 5. Риски будущего и предохранители

| Риск | Предохранитель |
|---|---|
| YouTube блокирует IP | `YTDLP_COOKIES`, прокси через `YTDLP_EXTRA_ARGS`; понятная ошибка |
| edge-tts отвалился | переключить пресет на `yandex_*` / `piper_irina` — одна строка |
| Postiz обновился и требует Temporal | `--profile temporal`, тег закреплён |
| Postiz 429 / упал | retry; `publish` перезапускаем отдельно из архива рана |
| LLM выдал невалидный JSON / выдуманную позу | zod, 3 попытки; поза нормализуется, запрос в очередь |
| Сгенерированный спрайт «уехал» от персонажа | никогда не попадает в рендер без превью и `--approve` |
| Диск | ретеншн ранов и raw |
| Юридика БАД | футер + запреты в промпте + `--mode draft` на первые 10–20 постов |

## 6. Локально или сервер — **сразу сервер**

Цепочка Linux-нативная; Postiz с IG/TikTok обязан быть на публичном HTTPS; setup идемпотентен, `doctor` показывает пробелы. «Ручной режим» — первые посты через `--mode draft`. Сервер: 4 vCPU / 8 ГБ (+4 ГБ swap) / 60 ГБ NVMe, Ubuntu 22.04+, не RU-IP для IG/TikTok или прокси.

| Этап | Что | Готово, когда |

| 0 (день 1, параллельно) | заявки на Facebook Business App (IG), TikTok Developer, YouTube OAuth, Telegram-бот, VK-приложение | заявки поданы |

## 8. Первый шаг (сегодня)

```bash
git clone <repo> /opt/autopostwb && cd /opt/autopostwb && git checkout claude/eloquent-lamport-pxecqs
sudo bash scripts/setup-server.sh && cp .env.example .env
npx skills add remotion-dev/skills            # официальные навыки Remotion для Claude Code
npm run doctor
npm run sprites:placeholder
PEXELS_API_KEY=... bash scripts/fetch-broll.sh "healthy food kitchen" 4
bash scripts/normalize-music.sh ~/tracks
CF_SCRIPT_PROVIDER=template npm run produce   # смоук
```

Дальше — этап 4: вписать `YANDEX_API_KEY`/`YANDEX_FOLDER_ID`, поставить `"defaultPreset": "yandex_alena"` и запустить `produce` ещё раз; параллельно этап 0 (заявки) и этап 5 (референс персонажа).
